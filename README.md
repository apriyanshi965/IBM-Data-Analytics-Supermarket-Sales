## Project Overview
This project presents an Exploratory Data Analysis (EDA) and dynamic Streamlit dashboard analyzing sales revenue, customer ratings, and payment trends across supermarket branches.

## Key Features
* Executive KPI Cards (Total Revenue, Items Sold, Transactions, Avg Rating)
* Interactive Product Line Revenue Chart (Plotly)
* Payment Method Share Breakdown
* Multi-select Filters for City and Product Category
